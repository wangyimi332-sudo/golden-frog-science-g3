# Golden Frog Science Island · Grade 3

面向亲子共学的科学英语网页游戏：8 章、96 个任务，包含英语配音、操作练习、研究基地与本机学习存档。

## 发布

这是独立的 GitHub Pages 发布目录。网页及所有运行素材在 `public/` 中。
在仓库 Settings → Pages 中选择 GitHub Actions；推送 main 分支后自动发布。
预计网址（发布成功后才可访问）：https://wangyimi332-sudo.github.io/golden-frog-science-g3/

## 更新与本地预览

更新 public 中的网页文件，提交并推送到 main。无需安装构建依赖。
本地可在 public 目录启动静态网页服务。使用相对资源路径，支持 GitHub Pages 项目子目录。

## 学习存档

亲子两个档案保存在各自浏览器中，不上传服务器。
迁移网址前请在原网站 My Learning 导出备份，在新网站同一页面导入。
本仓库不包含个人学习存档或教材 PDF。
