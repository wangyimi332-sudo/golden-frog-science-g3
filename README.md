# Golden Frog Science Island · Grade 3

面向亲子共学的科学英语网页游戏：8 章、96 个任务，包含英语配音、操作练习、研究基地与本机学习存档。

## 发布

完整静态网站保存在 `package/g3-pages.zip.part00` 至 `part09`。GitHub Actions 会合并分块、校验 ZIP 的 SHA-256、解包 `public/`，再发布到 GitHub Pages。分块方案用于可靠上传含 1,152 段音频的约 39 MB 发布包。

仓库 Settings → Pages → Build and deployment → Source 应选 **GitHub Actions**。发布成功后网址为 https://wangyimi332-sudo.github.io/golden-frog-science-g3/ 。

## 学习存档

亲子档案保存在各自浏览器中，不上传服务器。迁移网址前，请在原网站 My Learning 导出备份，并在新网站导入。本仓库不包含个人学习存档或教材 PDF。

## 内容说明

依据旧版 California Science Grade 3 编写的原创伴学活动，非出版社官方网站。插画为项目所有者提供的生成式插画；配音由 Kokoro-82M 生成。公开仓库不代表自动授予代码、插画或活动内容的再分发许可。
