# California Science Grade 3 · Golden Frog Science Island Grade 3 黄金蛙科学探险岛

G3 延续黄金蛙的探险地图，把学习重心从认识单一生物或材料，推进到比较环境、追踪变化和解释规律。八章共 96 个顺序任务，每章 12 关。孩子在操作模型、观察结果和英语拼句之间反复往返，逐渐学会用证据说明一个解释，也学会说出证据不足的地方。

## 取材与创作

依据 Macmillan/McGraw-Hill 2008 年版《California Science Grade 3》主教材的八章顺序与核心内容设计，覆盖教材印刷页 20–381。阅读文字、任务与研究模型为原创伴学材料，不复制教材原文、原题或整页插图。

## 全册章节

- 第 1 章 陆地环境中的适应｜比较沙漠、草原、森林和苔原中的生存条件、植物与动物结构，研究伪装、光照与保温。
- 第 2 章 水域环境中的适应｜研究海洋和湿地中的光、水、浮力与生物结构，比较栖息环境并用模型讨论水流与过滤。
- 第 3 章 环境变化｜观察生物怎样改变环境、洪水等变化怎样影响种群，并从化石记录区分过去的证据与推测。
- 第 4 章 地球、太阳与月亮｜用转动模型、日照记录和月相顺序解释昼夜、季节与月亮外观变化。
- 第 5 章 太阳系｜比较太阳、行星、望远镜与恒星，练习读图、辨别模型比例及说明观测工具能提供什么证据。
- 第 6 章 物质｜区分固体、液体和气体，使用粒子模型、性质和测量记录比较变化前后。
- 第 7 章 能量｜追踪能量形式、用途与传递，联系波和声音，用受控比较检验预测。
- 第 8 章 光｜研究光路、反射、颜色、透光材料和影子，用改变条件的模型解释所见现象。

## 学习方式

96 关按教材顺序开放；每关结合操作、证据判断与英文句子组织。全册有 11 个随进度建设的研究站，完成后可回看自己的证据；野外笔记保存观察与亲子讨论。Heart、Bella 两种预录英语声音支持慢速重听。

## 综合复习

关卡中的旧概念会换材料与情境再次出现，例如用光解释生境与影子，用环境变化回看水域和化石。My Learning 根据已完成任务列出至少一天后的复习候选，研究站提供证据回访；重玩不重复发放奖励。复习重点是能否把原有方法用于新问题，而非只记住第一次的答案。

## 期末检查与学习评估

当前在线版通过任务操作、证据首答、句子拼接、章节完成记录和回访表现观察学习情况。规划资料另有独立的 32 题期末研究挑战脚本，但这一独立考试尚未加入现版网站，不能作为已上线功能宣传。

## 成长模块与家庭学习

研究基地、分章野外笔记和 My Learning 形成现版成长记录：孩子可回看已完成的 96 关、首次证据答题、待复习任务和 11 座研究站；家长可用独立档案体验同一学习路径并讨论下一步问题。

## 培养的能力

重点培养跨环境比较、预测、控制单一条件、读取简单记录、连接证据与解释，以及用英语表达因果、相同与不同。课程内记录能显示任务完成与选择过程，不等同标准化语言或科学水平测评。
